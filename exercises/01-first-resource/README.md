# Exercise 01: Your First Terraform Resource

## 🎯 Objectives
- Understand the `terraform` configuration block and provider declaration.
- Configure the `hashicorp/local` provider.
- Declare a `local_file` resource to create a managed file on disk.
- Practice the core CLI workflow: `terraform init`, `terraform plan`, `terraform apply`, and `terraform destroy`.

## 📖 Key Concepts
- **Terraform Block**: Specifies the required Terraform CLI version and required provider plugins.
- **Provider**: A plugin telling Terraform how to interact with an API or target platform (e.g. AWS, GCP, Local, Docker).
- **Resource Block**: The primary HCL construct (`resource "<TYPE>" "<NAME>" { ... }`).
- **State File**: After `terraform apply`, Terraform records state in `terraform.tfstate`.

## 📝 Your Task
Navigate to `starter/`. Edit `main.tf` and `outputs.tf` to:
1. Define a `terraform` block requiring provider `hashicorp/local` (version `~> 2.5`).
2. Declare a `local_file` resource named `welcome_note` that:
   - Sets the target `filename` to `${path.module}/welcome.txt`.
   - Sets `content` to `"Hello, Terraform! I am managing infrastructure as code."`.
   - Sets `file_permission` to `"0644"`.
3. In `outputs.tf`, expose:
   - `file_path`: The path of the created file.
   - `file_id`: The unique ID generated by Terraform for this resource.

## 🧪 Verification Steps
```bash
cd starter
terraform init
terraform plan
terraform apply -auto-approve
cat welcome.txt
terraform output
terraform destroy -auto-approve
```
